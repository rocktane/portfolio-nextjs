# Logos

Sources consultées le 14 novembre 2026. Les paires `*-black.svg` et
`*-white.svg` conservent les mêmes tracés vectoriels, sans fond d’icône.
Les couleurs monochromes sont des adaptations de présentation pour le portfolio,
pas une affirmation que chaque marque publie ces deux variantes.

- **Claude** : symbole Claude, https://t3.codes/harnesses/claude-ai-icon.svg ; présent aussi dans le dépôt officiel T3 : https://github.com/pingdotgg/t3code/blob/main/apps/marketing/public/harnesses/claude-ai-icon.svg.
- **Codex** : symbole OpenAI employé par la référence T3, https://t3.codes/harnesses/openai_dark.svg.
- **T3 Code** : https://github.com/pingdotgg/t3code/blob/main/assets/prod/logo.svg. Fond carré retiré, tracé blanc officiel conservé, exporté également en noir. Le violet de la première version a été supprimé.
- **Hermes Agent** : https://github.com/NousResearch/hermes-agent/blob/main/assets/icon-master.svg et https://github.com/NousResearch/hermes-agent/blob/main/assets/icon-master-dark.svg. Le premier fournit la géométrie commune des deux exports, sans le fond carré. Aucun bitmap ni agrandissement du favicon.
- **OpenClaw** : https://openclaw.ai/brand/openclaw-mascot.svg. Contours officiels conservés, dégradé remplacé par l’encre monochrome et yeux évidés pour garder leur lisibilité dans les deux thèmes.
- **n8n** : https://github.com/n8n-io/n8n/blob/master/packages/frontend/%40n8n/design-system/src/components/N8nLogo/logo-icon.svg. Géométrie conservée, encre blanche/noire.

Les marques appartiennent à leurs propriétaires respectifs.
